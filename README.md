# SEC QUEST

情報セキュリティの知識がないと先に進めない、ドット絵のオープンワールド謎解きゲームです。
ヒントはありません。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(インストール不要)。

- 移動: 矢印キー / WASD
- 調べる・会話を進める: スペース / Enter

この世界では、画面の外にあるものもすべて「ゲームの一部」です。

## ファイル

- `index.html` … 本編
- `radio.html` … 別ゲーム「港ラジオ受信機」
- `js/` … ゲームのコード
- `css/` … 見た目
- `js/art.js` … ドット絵(すべてコードで描画)
- `js/assets-config.js` … 外部で描いた画像に差し替えるための設定

## ドット絵を画像に差し替える

`assets/` に PNG を置き、`js/assets-config.js` にそのパスを書くと、コードで描いたドット絵の代わりに使われます。

| 項目 | 形式 |
| --- | --- |
| `tiles` | 16×16 のタイルを横一列に並べた PNG(並び順は `assets-config.js` に記載) |
| `player` | 48×64 の PNG。横に「立ち・歩き1・歩き2」、縦に「下・左・右・上」向き |
