# SEC QUEST

情報セキュリティの知識がないと先に進めない、ドット絵のオープンワールド謎解きゲームです。
ヒントはありません。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(インストール不要)。

- 移動: 矢印キー / WASD
- 調べる・会話を進める: スペース / Enter

この世界では、画面の外にあるものもすべて「ゲームの一部」です。
